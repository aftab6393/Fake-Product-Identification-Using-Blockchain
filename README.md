AUTHENTIX–Blockchain Powered Anti-Counterfeit Plateform

A blockchain-powered web application to detect and prevent counterfeit products in the supply chain. This system verifies the authenticity of a product using unique identifiers and QR code scanning, ensuring trust between manufacturers, sellers, and consumers.

## 🚀 Project Description

This project addresses the growing issue of counterfeit goods by enabling secure product verification via blockchain. It provides roles for **manufacturers**, **sellers**, and **consumers**, with features like product registration, QR generation, real-time product verification, and immutable record-keeping on the blockchain.

## 🧰 Tech Stack

- **Frontend**: HTML, CSS, Bootstrap, JavaScript  
- **Backend**: Node.js, Express.js  
- **Blockchain**: Ethereum Smart Contracts (Solidity)  
- **Web3 Integration**: Web3.js / Ethers.js  
- **QR Code**: QR Code Generator and Scanner  
- **Database**:  MongoDB 
- **Deployment**: Render / GitHub Pages

## 🔑 Features

- 👨‍🏭 Manufacturer: Register products, generate QR codes, store product data on blockchain  
- 🛒 Seller: Scan and validate product authenticity before selling  
- 👥 Consumer: Scan QR to verify if a product is genuine or fake  
- 🔐 Blockchain Security: Immutable product tracking  
- 📸 QR Code Scanning: Real-time scan and verification  
- 🧾 Smart Contract Integration: Secure, decentralized product record

## 📦 Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/aftab6393/Fake-Product-Identification.git
cd Fake-Product-Identification

2. Install dependencies
bash
npm install

3. Start the development server
bash
npm run dev

4. Deploy Smart Contracts (if using local blockchain)
Use tools like Truffle to compile and deploy smart contracts.
